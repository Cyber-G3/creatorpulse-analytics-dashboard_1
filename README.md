# CreatorPulse Analytics

Dashboard académico de ejemplo para visualizar ingresos, afiliación, colaboraciones de marca y rendimiento en redes sociales.

## Abrir el proyecto

Abre `index.html` en un navegador con conexión a Internet. Tailwind CSS v4 se carga desde el CDN oficial usado por el ejercicio.

## Qué muestra el dashboard

- Ingresos totales de demostración: **$42,500.00**.
- Ingresos netos estimados de la creadora: **$36,125.00**, tras una comisión ilustrativa del 15%.
- Impacto de audiencia y engagement medio.
- Distribución de ingresos entre Instagram, TikTok y YouTube.
- Productos afiliados con precio, ingresos y tasa de conversión.
- Colaboraciones de marca con estado, seguidores, ingresos, pago estimado y ROI.
- Indicadores resumidos de clics, visualizaciones y actividad por plataforma.

## Tecnologías

- HTML5 semántico.
- Tailwind CSS v4 mediante `@tailwindcss/browser@4`.
- Sin frameworks, backend ni APIs.

## Datos y limitaciones

Todas las cifras, marcas, nombres y variaciones son ficticios y sirven únicamente para la demostración. El dashboard no está conectado a redes sociales, marcas ni plataformas de afiliación. Los filtros, botones de descarga y acciones de campaña son elementos visuales; no ejecutan operaciones.
